# KnowBeforeYouGo - Singapore Guide

A free, bilingual (English & Tamil) awareness portal for Tamil-speaking visitors and workers traveling to Singapore. Know the rules before you go.

## 🌐 Live Site

**URL:** [https://www.knowbeforeyougo.in/](https://www.knowbeforeyougo.in/)

## 📋 Overview

KnowBeforeYouGo provides essential information about:

- **Work Passes** - Work Permit, S-Pass, Employment Pass guides (3-phase approach)
- **Visas** - Tourist visa, entry requirements, and pass options
- **Singapore Laws** - Critical laws including drug trafficking, smoking restrictions, littering penalties
- **Do's & Don'ts** - Cultural etiquette and behavioral guidelines
- **Travel Tips** - MRT/public transport, weather, SIM cards, healthcare, cost of living
